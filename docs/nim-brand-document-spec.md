# Document Brand Specification: New Initiatives Marketing

> Source: http://www.newinitiativesmarketing.com  
> Applied in NIM Content Studio UI, blog preview, and Word-style editor.

## Core palette

| Role | Hex | Usage |
|------|-----|-------|
| Primary | `#555672` | Headings, links, table headers, bullets |
| Secondary | `#f27028` | Sub-headings, dividers, primary buttons |
| Accent | `#f5bb48` | Highlights, pull quotes |
| Background | `#f3f3f5` | App / page background |
| Body text | `#333333` | Body copy |

## Typography

- **Headings (Major):** Montserrat 600/700
- **Body (Minor):** Calibri / Carlito fallback, 17pt in documents

## Document heading hierarchy

- **Title / H1:** Montserrat, primary `#555672`
- **H2 / H3:** Montserrat, secondary `#f27028`
- **Body:** Calibri, `#333333`, line-height ~1.5
